# 07 — 功能模块清单与验收

> 目的：确保"功能一个都不能少"。本文档逐功能列出**桌面版真实能力 → Web 化方案 → 验收标准**。
> QA 以本清单逐条验收；每条通过即视为该功能无缺失迁移。

---

## A. AI 对话模块

| 功能 | 桌面真实行为 | Web 方案 | 验收标准 |
|------|------------|---------|---------|
| 多轮对话 | agent:run + 流式 | SSE 流式 | 输入消息，token 逐字流出 |
| 对话历史 | conversations/messages 表 | REST | 切换对话能加载历史消息 |
| 思考模式 | thinkingEnabled，reasoning 折叠为 `<details>` | 保真 | 开启后显示"💭 思考过程"折叠块 |
| 工具调用展示 | tool-call/tool-result 卡片 | SSE 同事件 | 调用工具时显示工具名+参数+结果 |
| 危险操作确认 | delete_* 弹确认，60s 超时 | SSE + /agent/confirm | 删除类操作弹确认框，取消则不执行 |
| 中止生成 | agent:abort | /agent/abort | 点停止能中断流 |
| Agent 角色（28个） | soulContent 注入 system | 静态资源 | 切换角色后回答风格/system 变化 |
| 联网搜索 | web_search(Tavily) | 后端代理 | 配置 key 后能联网检索并引用 |
| RAG 知识库注入 | 余弦相似度 top3 | pgvector 下推 | 提相关问题时回答引用了笔记内容 |
| 跨会话记忆 | 三层加载+遗忘曲线 | 同算法+userId | 新会话能 recall 之前 save 的记忆 |
| 记忆 AI 整理 | consolidate | 异步任务 | 触发后记忆被合并/去重 |
| Token 统计 | usage 累计入 token_stats | 同 | 对话后统计数据增长 |
| 流断容错 | 非流式降级 | 保真 | 弱网下不卡死，有兜底回复 |
| 对话存为笔记 | source_type/source_msg_id | REST | 消息可一键存为笔记并溯源 |
| 导出对话 | conversations:export | /export | 能导出单个对话 |

## H. 端到端验收脚本（建议）

1. 注册两个账号 U1/U2，验证数据互不可见（隔离）。
2. U1 配置 API Key → 发起对话 → 流式输出 → 触发 create_note 工具 → 笔记本出现新笔记。
3. U1 触发 delete_note → 弹确认 → 取消 → 笔记仍在；再确认 → 删除。
4. U1 建语义索引 → 语义搜索召回相关笔记 → 对话中 RAG 引用笔记。
5. U1 save_memory → 新开会话 recall_memories 命中。
6. U1 让 AI 生成 docx → 返回下载链接 → 下载文件正常打开。
7. U1 创建插件指向内网地址 → 被 SSRF 防护拒绝；指向合法地址 → AI 可调用。
8. U1 配置 Memos → 同步 → 双向数据一致，删除传播。
9. U1 导出 JSON → U2 无法访问 U1 数据；U1 重新导入数据完整。
10. 弱网模拟流中断 → 有兜底回复，不卡死。
11. U2 用 U1 的 noteId 直接请求 → 返回 403/404（防 IDOR）。
12. 敏感配置接口返回掩码，抓包确认无明文密钥下发前端。
